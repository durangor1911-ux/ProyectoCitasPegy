# CitasPeggy

Plataforma de agendamiento de citas en tiempo real para negocios de servicios (restaurantes, consultorios, spas, barberías, etc.).

## Descripción del proyecto

CitasPeggy permite a los clientes autogestionar la reserva de citas de forma directa y rápida: seleccionar servicio, especialista, fecha y hora, y obtener un comprobante digital. A los negocios les permite reducir llamadas de atención, minimizar inasistencias y maximizar la ocupación de su agenda.

**Proyecto integrador** desarrollado bajo metodología ágil Scrum.

## Objetivos de negocio

- Reducir llamadas de atención al negocio
- Minimizar inasistencias (no-shows)
- Maximizar la ocupación de agenda

**Métricas de éxito:** 0% citas cruzadas · Agendamiento en menos de 2 minutos · Menos citas completadas que canceladas
